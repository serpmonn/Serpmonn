Serpmonn Direct API — внутренняя спецификация

Назначение
Серверный скрипт (Node.js) для управления собственными
рекламными кампаниями аккаунта Serpmonn в Яндекс.Директ.

Стек
- Node.js
- HTTPS
- JSON API Яндекс.Директ v5
- OAuth-приложение (application_id): 5fff458b3fc647e2b8ee0939f23b75a6

Основные методы API
- campaigns.get / campaigns.update
- ads.get / ads.update / ads.moderate
- reports (получение статистики)

Публичный UI отсутствует.
Приложение используется только для управления
собственным рекламным кабинетом Serpmonn.
Сторонним рекламодателям и внешним пользователям
Директа доступ не предоставляется.

Сайт: https://serpmonn.ru
Контакт: support@serpmonn.ru

Messenger

P2P и end-to-end: сообщения идут напрямую между устройствами — без доступа серверов к переписке.

Android 8.0+ · бесплатно

Ранний публичный релиз. Возможны сбои и изменения. Для критически важных данных пока лучше иметь запасной канал связи.

Экраны

Список чатов, блокировка, обмен контактом по QR и настройки на устройстве.

Как это устроено

Шифрование на устройстве. Прямое соединение. Локальная история.

End-to-end

Сообщения шифруются на устройстве и расшифровываются только на стороне получателя. Ни серверы, ни Serpmonn содержимое не видят.

Прямое P2P

Устройства соединяются напрямую. Если сеть мешает — включается резервный зашифрованный маршрут, E2E сохраняется.

Офлайн и группы

Bluetooth и локальный Wi‑Fi без интернета. Личные и групповые чаты, обмен контактами по QR, история на устройстве.

Скачать

RuStore — с обновлениями. APK — прямая загрузка. Windows EXE — ранняя альфа.

Как установить из RuStore?

Открывается страница приложения в RuStore → «Установить». Обновления приходят через магазин.

Windows EXE?

Ранняя альфа для Windows 10/11, установщик не нужен. Если SmartScreen предупреждает — «Подробнее» → «Выполнить в любом случае».
